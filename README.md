Desarrollé esta app como Prueba de Concepto para algunos ejercicios vistos en el curso de Android de [Hextree.io](https://hextree.io).

En esta se cubren temas principalmente de interacción con los servicios Android más utilizados:

- Arranque de servicios **Non-bindable**
- Ciclo de vida de un servicio
- Servicios bindable tipo **Message Handler**
- Respuestas a servicios **Message Handler**
- Servicios bindable tipo **AIDL**
- Carga dinámica de interfaces **AIDL**
